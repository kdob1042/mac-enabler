# 中断・圧縮・引き継ぎ

工程と必須項目は `config/workflow.json` が正本。この文書は保存先と再開手順を示す。モデル選択は[README](../README.md#モデルを選ぶ)を参照する。

## 中断前に保存

対象repoのIssue／PRへ次を残す。repoが別の永続的な作業記録を定める場合はそれを使う。会話だけを正本にしない。

```markdown
- 目標・対象範囲・制約:
- 正本と読む順:
- 担当・ブランチ・Issue／PR:
- head SHA・検証済みSHA:
- 変更ファイル・未push変更・未共有成果物:
- 検証結果・未実行項目と理由:
- 残件・未解決の判断:
- 次の一手:
- 選択したroute／profile（使用時のみ）:
```

短い作業でも再開位置と次の操作を残す。失敗や未検証を完了へ読み替えず、資格情報を含めない。担当交代時は[併用の手順](cursor-codex.md#担当を交代する)も確認する。

## 再開

1. 適用範囲内のAGENTSと最新の引き継ぎを読む。
2. 現在のブランチ・PR・head SHA・未コミット／未push変更を照合する。
3. 記録された次の一手から進める。差分がなければ探索を繰り返さない。

コンパクションはホストの機能でありrepoから強制できない。自動圧縮に備えて作業の区切りで保存する。保存できなかった場合は会話へ残し、永続化できていないことを明記する。
